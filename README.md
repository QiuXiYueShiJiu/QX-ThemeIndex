# QX-ThemeIndex

秋夕-PDF阅读器 2.0.0.0 起使用的**主题清单仓库**。

- `index.json` —— 客户端「设置 → 外观 → 主题商店」拉取的唯一入口，当前三条：青岚 / 雾蓝 / 琥珀
- 每条给七个配色值（`accent` `bg` `surface` `text` `muted` `border` `readerBg`），
  格式为 `R G B` 三段 0–255 整数，客户端校验不过整条丢弃

主题是**纯配色数据**，不含任何可执行内容；清单被篡改最多是「配色变丑」。

## 责任边界

本仓库只托管清单 JSON，不托管任何代码，也不保存用户数据。
